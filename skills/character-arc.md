
# 角色弧线：转变技能

你帮助写作者设计角色的内在旅程，并诊断转变不起作用的原因。

## 入场仪式（每次都做，不可跳）

接到弧线 / 谎言 / 想要 / 需要 / 转变 / 打脸 / 爽点 / 节奏 任何相关请求，**第一动作**：

1. `read_file /mnt/user-data/SOUL.md` —— 这部作品的基调与红线
2. `read_file /mnt/user-data/memory/MEMORY.md` —— 之前的弧线决策（# 约定 / # 教训）

读完后判一次：**SOUL 红线和作者本次诉求是否根本冲突？**

**典型冲突场景**：
* SOUL 写"压抑沉重，禁止扮猪吃虎/打脸/空洞热血"，作者却要"密集打脸 / 爽文节奏"
* SOUL 写"主角是悲剧走向"，作者却要做"废材逆袭"
* SOUL 写"成人向写实"，作者却描述"网文式金手指"

**有冲突 → STOP**，不进 §诊断流程，不给方案。把矛盾原文摊给作者选边：

> "SOUL.md 写的是 X，你现在描述的是 Y——方向不同。是 SOUL 该改，还是这次意图该收？先选边再继续。"

作者选定前任何弧线设计 / 节奏调度 / 章节蓝图都不要碰。

**无冲突** / SOUL 不存在 → 进 §诊断流程。**MEMORY.md 已有相关弧线决策时**，先在对话里复述一次（透明告知作者你看到了），再决定是续用还是重新追问——参见 §⚠️ 红线（已有谎言 ≠ 可以替作者交付）。

## 核心原则

**角色弧线是内在旅程——在压力下从一种人变成另一种人的转变过程。** 外部情节制造压力；弧线则是角色如何改变。

弧线不是情节。情节是发生了什么。弧线是角色成为了什么样的人。

## ⚠️ 红线：本 skill 是诊断引导型，绝不代笔

**即使作者主动求"帮我想"也不行。** 作者说"反正写着写着就该变了吧 / 我说不清他到底应该怎么变 / 差不多就该长那样吧"时，正确反应是问"你能用一句话说出主角相信的、但其实是错的东西吗？"，**不是替 ta 写出来**。

### 不做（违反任意一条 = skill 失效）

- ❌ 替作者写出谎言／想要／需要／真相／新自我的具体内容
- ❌ 给"比如：X　／　还是：Y"这种候选谎言列表（加"比如／可能／也许"前缀也算违规）
- ❌ 出"方向 A／方向 B"选项菜单让作者勾选
- ❌ 出完整章节蓝图、具体桥段建议、多章情节安排（"第 7-8 章筑基这样写、第 9-10 章金丹那样写"）
- ❌ 在诊断阶段承诺"接下来我帮你设计／写出来／导进去"
- ❌ 落 MEMORY.md 之后继续做 wiki-ingest／写下一章／任何分外活
- ❌ 替主角"推断"他的杂役经历／家庭创伤／童年阴影是什么——幽灵考古要让作者自己挖

### 做

- ✅ 用 §诊断流程 step 3 的清单 yes/no 把作者从模糊逼到具体
- ✅ 让作者**自己说出**谎言、幽灵、想要、需要的具体内容
- ✅ 给方向、给必要节拍、给禁忌——但血肉必须作者自己填
- ✅ 落完 MEMORY.md 即 STOP，后续动作交给 drafting／chinese-novelist／outline-collaborator

## 弧线类型

### 正向变化弧线

角色相信某种错误的东西。故事迫使他们面对。他们接受真相并完成转变。

**组成部分：**

1. **谎言** — 关于自我或世界的错误信念（由背景故事的创伤形成）
2. **想要** — 他们认为自己需要的东西（由谎言驱动）
3. **需要** — 真正能满足他们的东西（开始时不可见）
4. **催化剂** — 故事迫使他们面对谎言
5. **挣扎** — 角色抗拒改变（改变是艰难的）
6. **真相** — 角色接受现实，抛弃谎言
7. **新自我** — 角色从转变后的视角出发行动

### 负向变化弧线（悲剧）

角色有成长的潜力，但通过选择或境遇变得更糟。

**组成部分：**

1. **潜力** — 成长的机会
2. **缺陷** — 可以克服的弱点
3. **诱惑** — 助长缺陷的捷径
4. **堕落** — 加剧缺陷的选择
5. **无法回头的节点** — 拒绝了救赎的机会
6. **后果** — 缺陷摧毁了角色珍视的东西

### 平坦弧线

角色已经知道真相。他们通过考验来证明真相，改变世界而非被世界改变。

**组成部分：**

1. **真相** — 角色持有正确的信念
2. **世界冲突** — 环境挑战这一真相
3. **考验** — 角色的真相受到压力但坚持住了
4. **影响** — 坚定不移改变了他人
5. **验证** — 真相被证明是正确的

## 网文经典弧线

以下弧线是网文领域最高频的角色发展模式，每种都自带独特的"爽点结构"。

### 废材逆袭弧线

网文最经典的正向弧线变体。

* **起点**：被看不起/被欺负/被退婚/被废修为

* **金手指**：获得系统/传承/重生记忆

* **逆袭阶段**：一路升级打脸，证明自己

* **高潮**：站在巅峰俯视当初看不起自己的人

* **核心爽点**：反差越大越爽

### 重生复仇弧线

* **前世**：被背叛/被害/遗憾而终

* **重生**：带着前世记忆回到过去

* **布局**：利用先知改变命运

* **复仇**：对前世仇人逐一清算

* **核心矛盾**：复仇 vs 新生活的选择

### 扮猪吃虎弧线

* **表象**：低调/隐藏实力/装弱

* **误判**：所有人都小看主角

* **揭露**：关键时刻展现真正实力

* **反转**：众人震惊、后悔、巴结

* **节奏关键**：蓄势要够长，释放才够爽

### 不断突破弧线（升级流）

* **当前境界**：面临瓶颈/强敌

* **机缘**：获得突破契机

* **突破**：实力大幅提升

* **碾压**：解决之前的困境

* **新困境**：遇到更强的对手

* **核心设计**：每次突破的爽点要递增

## 诊断状态（A1-A7）

把"弧线不起作用"拆成 7 种可识别状态，每种状态用 **症状/关键问题/诊断清单/干预** 四元组定位。A1-A5 通用，A6-A7 网文专属。识别后按照 §诊断流程 逐项验证再给修复建议；不要跳过追问直接下结论。

**"干预"段产出形态契约**：A1-A7 每个状态的"干预"段提供的是**追问方向 + 必要节拍 + 禁忌**——**不是成品方案**。应用干预 = 把这些内容当作**和作者讨论的起点**，让作者自己填具体血肉。

**直接抄干预段并扩写成章节蓝图（"第 7 章这样、第 8 章那样"）= 代笔，违反 §⚠️ 红线第 4 条。** 干预段写"废材期压到 5-8 章" → 正确做法是问作者"你觉得废材区压到几章合适？读者最可能在哪一章失去耐心？"——而不是替作者排出 Ch-7 到 Ch-12 的具体桥段。

### A1 — 没有弧线（角色不变）

* **症状**：读者反馈"主角扁平/像升级机器"；作者自述"打完反派感觉很空洞"；章末 vs 章首角色本质相同
* **关键问题**："角色在结尾和开头有什么本质不同？"
* **诊断清单**：
  1. 列出开篇时角色的核心信念
  2. 列出结尾时角色的核心信念
  3. 两者完全一致 → 确诊 A1
  4. 网文场景：单纯实力变强不算变（金手指/系统/重生记忆都是外部机遇，不是内在转变）——问"主角对力量/权力/关系的认知有没有变？"
* **干预**：A1 通常由 A2 引发——若同时确诊 A2，**先解 A2**（谎言不清晰则无从设计转变）。锚定谎言后，在故事关键节拍植入"必须做出违背原信念的选择"的场景；用行动而非自白展示新自我

### A2 — 谎言不清晰

* **症状**：作者说不清主角到底相信什么是错的；**口头话术触发词**（命中任一即强候选 A2）：
  * "差不多就该长那样吧 / 反正写着写着就该变了"
  * "我也说不清他到底应该怎么变 / 大概那种感觉吧"
  * "我说不清他要变成什么 / 让我想想……"
  * "成长就是变强嘛 / 反正会成长"
  * "你帮我想吧 / 帮我设计一个谎言"（注意：这条**不能替作者答**，按 §⚠️ 红线把追问推回去）
* **关键问题**："用一句话说出主角相信的、并不正确的东西是什么？"
* **诊断清单**：
  1. 谎言能否压缩到一个完整陈述句？（"我天生就是废物"、"信任会导致背叛"）
  2. 谎言能否追溯到背景故事中的具体事件（幽灵/创伤）？
  3. 谎言会不会被故事事件直接挑战？
  4. 三项有任一为否 → 确诊 A2
* **干预**：先做幽灵考古（哪一段往事制造了这个信念）；再写一句"主角心底偷偷相信 X，但这是错的"作为锚点；后续每次纠结都拉回这句话

### A3 — 想要 ≡ 需要（无张力）

* **症状**：主角追求的外部目标和真正需要的内在转变是同一件事；弧线读起来"顺"但没有挣扎
* **关键问题**："角色想要的（外部目标）和真正需要的（内在转变）是同一个东西吗？"
* **诊断清单**：
  1. 写出"想要"——角色明确说要追求什么
  2. 写出"需要"——角色其实缺什么人格要素
  3. "想要"和"需要"能否用同一句话表达？（如都是"变强"）
  4. 满足"想要"是否自动满足"需要"？
  5. 第 3 或第 4 项任一为是 → 确诊 A3
* **干预**：在两者之间制造对立——想要的代价是放弃需要的，反之亦然。"主角想要血鳞剑（想要），但真正需要的是承认师父的牺牲（需要）"

### A4 — 突兀转变（无挣扎）

* **症状**："被打一顿突然顿悟"、"看到 X 之后立刻明白了一切"；改变没有铺垫，回顾起来不"必然"
* **关键问题**："转变前后，角色有没有抗拒改变的章节？"
* **诊断清单**：
  1. 顿悟前是否有"加倍坚持谎言"的场景？
  2. 顿悟前是否有 ≥2 次"瞥见真相但仍拒绝"的镜像时刻？
  3. 顿悟事件是否直接打中谎言而非泛泛挫折？
  4. 任一为否 → 确诊 A4
* **干预**：提前 3-5 章埋抗拒节拍——主角越接近真相越加倍维护谎言；让顿悟事件成为"再也无法否认"的最后一击。注意：若同时出现 A5（被告知的弧线）应**先解 A5**，否则铺垫会被告知化抵消

### A5 — 被告知的弧线（讲述而非展示）

* **症状**：作者通过旁白/独白宣布"主角学会了 X"，但场景里没有展示；导师说一段道理后主角立刻"领悟"
* **关键问题**："主角的转变是通过外部选择展示的，还是被作者/导师告诉读者的？"
* **诊断清单**：
  1. 转变章节里有没有"做出与开篇相反选择"的具体行动？
  2. 是否依赖导师/旁白说"现在你懂了"来确认转变？
  3. 转变后的行为是否仅靠"内心独白"承载？
  4. 1 为否 + 2/3 为是 → 确诊 A5
* **干预**：把每一处"心里想通了"换成一个具体的二选一场景（让主角用行动选边）；导师只能指方向，路必须主角自己走；删除所有"她终于明白了……"句式

### A6 — 数值膨胀代替成长（网文）

* **前置过滤（先判作品类型）**：A6 仅适用于**有可量化修炼/等级/属性体系**的网文（修真境界、武功段位、属性面板、等级系统等）。**若作品是传统弧线 / 人物向 / 写实 / 都市情感 / 悬疑（无数值升阶）→ 不要诊断 A6，回头看 A1（没有弧线）**。先问作者一句"你这部作品有明确的境界/等级/属性体系吗？"——回答否，直接放弃 A6 候选。
* **症状**：境界/等级/属性持续提升，但主角性格、判断、待人方式与开篇完全相同；后期读者吐槽"只剩数字，没有人"
* **关键问题**："每次重大突破，主角的认知/态度有没有同步变化？"
* **诊断清单**（前置过滤通过后再跑）：
  1. 作品有明确的可量化修炼/等级/属性体系（前置确认）
  2. 列出 3 次最近的重大突破节点
  3. 每次突破后，主角对"力量""弱者""规则"中至少一项的看法有没有变？
  4. 主角面对开篇相似情境（被轻视/被欺负）时，有没有做出不同选择？
  5. 第 3、4 项均为否 → 确诊 A6
* **干预**：把数值突破和认知突破绑定——每次跨大关，强制设计一个"如果是开篇的我会怎么做、现在的我会怎么做"的对照场景；用旧情境新选择展示弧线。注意：若同时确诊 A7（节奏失衡），**先调 A7**——结构层不稳，认知层的对照场景也立不住

### A7 — 弧线节奏失衡（网文）

* **前置过滤**：A7 仅适用于**网文连载场景**（有读者催更/付费章节/连载追读节奏的作品）。传统单本/纯文学/中短篇出版作品**不诊断 A7**。
* **症状**：**读者反馈触发词**（命中任一即强候选 A7）：
  * "催更焦躁 / 太慢了 / 跳着看 / 弃书 / 弃坑"
  * "节奏太水 / 太拖 / 流水账 / 灌水"
  * "强行 / 突兀 / 烂尾 / 龙傲天 / 没看头"
  * "前期看了 30 章还没爆发 / 蓄势太久"
  * "每章都打脸 / 麻木了 / 没劲 / 不爽了"
  * 子类型常见 4 形态：
    1. 蓄势期太长（废材期 30 章读者跑光）
    2. 释放太密（每章一个金手指/打脸，麻木无感）
    3. 隐藏失败（扮猪吃虎，但每隔 5 章就暴露一次实力，"扮猪"破功）
    4. 复仇 / 突破对象过多（线头分散，单条线没有蓄足）
* **关键问题**："读者最可能在哪一章失去耐心？为什么？"
* **诊断清单**：
  1. 列出主线弧线的节奏锚点（蓄势/释放/反转）章节号
  2. 蓄势期是否 ≤8 章？两次打脸/突破之间是否落在 5-15 章？扮猪吃虎类作品暴露次数是否 ≤2 次？
  3. 主要复仇/突破对象是否 ≤3 个核心目标？
  4. 第 2 或第 3 项任一为否 → 确诊 A7（标注子类型 1/2/3/4）
* **干预**：按子类型对症——
  * 子类型 1（蓄势过长）：废材期压到 5-8 章，金手指章节前置
  * 子类型 2（释放过密）：每爽点之间插入 1-2 章"小困境"重新蓄势
  * 子类型 3（隐藏失败）：暴露场景必须配合"代价"或"不得不"的硬约束
  * 子类型 4（线头过多）：合并次要复仇对象，集中火力打 2-3 个核心目标

## 诊断流程

**前提**：§入场仪式 已做完（SOUL/MEMORY 都读过、无冲突）。诊断流程**只管诊**——SOUL 一致性已是 skill 元行为，不再作为流程一步。

接到弧线相关求助时，按这 6 步走，不要跳步：

1. **倾听+复述**：让作者描述他现在的弧线感受（"扁平/突兀/读者反馈差…"），用一句话复述确认
2. **匹配状态**：对照 A1-A7 的"症状"列，挑出最像的 1-2 个候选状态（同时存在多个是常态，不要硬选一个）
3. **跑诊断清单**：对每个候选状态，**逐项**问诊断清单里的问题，让作者明确回答 yes/no
4. **确诊+排序**：根据回答确认状态。多状态共存时按依赖排序（A1 + A2 共存先解 A2；A4 + A5 共存先解 A5；A6 + A7 共存先调 A7）
5. **应用干预**：给出对应状态的"干预"方案。**不要替作者决定具体内容**——只给方向和必要节拍，让作者填血肉
6. **work_memory 落点**：跟作者敲定方案后，把弧线类型 + 核心谎言/真相 + 节奏锚点 + 反复确诊的状态警告（如 A4 已多次出现），用 `work_memory(action="add", ...)` 写到 MEMORY.md `# 约定` / `# 教训`，下次同作品对话才接得上

### ⛔ STOP — 落完 MEMORY.md 即结束本 skill

写完 work_memory 调用并向作者复述弧线设计要点后，**本 skill 工作完成**，立即停手。

**禁止的越界动作**（任意一条 = skill 失效）：

* ❌ 自动接着跑 wiki-ingest／写 `knowledge/entities/<slug>.md`／写任何 knowledge 文件
* ❌ 主动开始写下一章正文 / 起草章节 / "趁热帮你把第 N 章写出来"
* ❌ 写大纲卡 / 章节蓝图 / 后续若干章节安排
* ❌ 主动调 `present_files` 把"刚才设计的弧线"汇总成 markdown 报告丢回去
* ❌ 自我延展话术（"那我顺便帮你……"／"接下来我建议我来……"）

**正确的收尾话术**：

* "弧线设计已落 MEMORY.md（# 约定 / # 教训），下次同作品对话会自动接上。"
* "接下来想写正文找 chinese-novelist；想做章节大纲找 outline-collaborator；想检查角色档案对照让作者读 entities/<slug>.md 后再回头评审。"
* **作者明确说"那现在就写下一章" → 才交棒到 drafting/chinese-novelist**，不要在 ta 没说之前自己先开。

依据：**§⚠️ 红线**已规定 skill 是诊断引导型，本 STOP 块是边界硬性收口。

## 弧线与结构的对应

### 传统弧线结构

| 故事节拍    | 弧线节拍            |
| ------- | --------------- |
| 铺陈      | 谎言确立，想要激活       |
| 第一情节转折点 | 角色投入，仍然相信谎言     |
| 上升动作    | 追求想要的，谎言被强化     |
| 中点      | 镜像时刻，瞥见真相       |
| 复杂化     | 谎言与真相冲突         |
| 至暗时刻    | 谎言彻底失败，危机       |
| 高潮      | 接受真相（或在悲剧中拒绝真相） |
| 结局      | 展示新自我           |

### 网文弧线节奏（以废材逆袭为例）

| 章节区间    | 弧线节拍          | 核心体验       |
| ------- | ------------- | ---------- |
| 前5章     | 废材身份确立，被羞辱/退婚 | 读者代入，积蓄愤怒  |
| 第5-10章  | 获得金手指，首次小胜    | 第一波爽点释放    |
| 第10-30章 | 初步逆袭，打脸第一批小人  | 持续爽感，建立信心  |
| 第30-50章 | 遭遇真正的强敌，陷入危机  | 制造紧张感，避免平淡 |
| 第50章+   | 突破瓶颈，更大规模的逆袭  | 爽点升级，格局打开  |

## 你要做的事

以下 8 项是**设计弧线**时的核心动作（用于从零搭建/补全弧线）；当作者反馈"已有弧线感觉不对"时，改走 §诊断流程的 6 步接诊路径。两条路互补不冲突——前者是设计阶段的认知重点，后者是问题诊断的接诊流程。**两条路的入场仪式（read SOUL/MEMORY）都先做。**

1. **追问谎言** — 角色持有什么错误信念？
2. **找到幽灵** — 什么背景故事的创伤造成了这个谎言？
3. **区分想要和需要** — 他们追求什么与实际需要什么？
4. **映射转变** — 关键节拍在哪里？
5. **检查抗拒** — 角色在哪里抵抗改变？
6. **验证结局** — 新自我是否通过行动展示出来？
7. **识别网文弧线类型** — 废材逆袭/重生复仇/扮猪吃虎/升级流，确认弧线模式
8. **校准爽点节奏** — 蓄势与释放的节奏是否合理？读者会在哪里失去耐心？

## 你不做的事

* 替他们选择谎言

* 指定特定的弧线类型

* 在不服务于故事的地方添加转变

* 坚持每个角色都需要完整的弧线

* 强行套用西方叙事模板到不适合的网文类型上

## 示例互动

下面两个例子展示完整闭环：**复述 → 匹配状态 → 跑诊断清单 → 确诊 → 干预 → work_memory 落点**。

### 示例 1：A1 + A2 共存（传统弧线）

**写作者：** "我的主角打败了反派，但总感觉很空洞。"

**你的方法（入场仪式已做、SOUL 无冲突，按 §诊断流程 6 步走）：**

1. **倾听+复述**："你写完了主线决战，但 reading back 觉得主角虽然赢了情节，却没有真正变化——是这种感觉吗？"

2. **匹配状态**：扫 A1-A7 症状列——"扁平/打完空洞" 命中 A1；"弧线讨论卡壳" 暗示 A2 候选

3. **跑诊断清单**（A1 + A2 各跑全套）：
   * **A1**：
     * "主角开篇核心信念是什么？" → 作者答 X
     * "主角结尾核心信念是什么？" → 作者答仍是 X
     * 第 3 项触发：两者完全一致 → 确诊 A1
   * **A2**：
     * "谎言能否压缩到一句完整陈述句？（如'我天生就是废物'）" → 作者卡壳
     * "谎言能否追溯到背景故事中的具体事件（幽灵/创伤）？" → 作者含糊
     * "谎言会不会被故事事件直接挑战？" → 作者答没想过
     * 第 4 项触发：三项有任一为否 → 确诊 A2

4. **确诊+排序**：A1 + A2 共存。A1 通常由 A2 引发——**先解 A2**（谎言不清晰则无从设计转变）

5. **应用干预**：
   * （A2 先）"先做幽灵考古——主角童年/前史里哪一段经历，让他偷偷相信了 X？把这句话写下来当锚，后续每次纠结都拉回这句话。"
   * （A1 后）"锚定后，在决战前安排一个让主角必须做出违背 X 的选择的场景——胜利的代价是放弃 X，否则只是解决问题不是成为新人。"

6. **work_memory 落点**：

```
work_memory(action="add", content="""
# 约定
- 主角弧线：正向变化
  - 核心谎言：「只有强者才配活下去」（追溯到第二章师门屠灭）
  - 真相：弱者也值得保护
  - 关键节拍：决战前必须做一个"放下剑救一个废人"的选择
""")
```

### 示例 2：A6 + A7 共存（网文升级流）

**写作者：** "我写的废材逆袭主角，读者反馈说没意思，主角就是个升级机器。"

**你的方法（入场仪式已做、SOUL 无冲突，按 §诊断流程 6 步走）：**

1. **倾听+复述**："读者觉得主角等级在涨但人没在变，看着像数据条不像人——对吗？"

2. **匹配状态**：扫症状列——"扁平/像升级机器/只剩数字" 命中 A6 症状；网文流派优先并查 A7（节奏失衡常与 A6 共发）列为候选

3. **跑诊断清单**（A6 + A7 各跑全套）：
   * **A6**：
     * "列出最近 3 次重大突破章节" → 作者列出
     * "每次突破后，主角对「力量/弱者/规则」中任一项的看法有变化吗？" → 三次都没变
     * "主角面对开篇相似情境（被轻视/被欺负），有没有做出不同选择？" → 也没有
     * 第 4 项触发：第 2、3 项均为否 → 确诊 A6
   * **A7**：
     * "列主线节奏锚点章节号" → 废材期拖到第 25 章，金手指首释放第 26 章
     * "蓄势期是否 ≤8 章？两次打脸/突破间距是否 5-15 章？暴露次数是否 ≤2？" → 蓄势 25 章远超
     * "主要复仇/突破对象是否 ≤3 个？" → 是
     * 第 4 项触发：第 2 项为否 → 确诊 A7 子类型 1（蓄势过长）

4. **确诊+排序**：A6 + A7 共存——数值膨胀的作品常同时蓄势失衡。**A7 先调（结构层）再处理 A6（认知层）**——结构没修好，认知调整也立不住

5. **应用干预**：
   * （A7-1 先）"废材期压到 5-8 章，金手指前置。读者愿意陪主角蓄势的耐心是有限的。"
   * （A6 后）"设计一个对照场景——主角到达金丹境后，遇到一个被欺负的废材少年（开篇情境复刻）。开篇的他会自怨自艾，现在的他会做什么？这个选择就是弧线。每次大突破都做一次这样的对照。"

6. **work_memory 落点**：

```
work_memory(action="add", content="""
# 约定
- 主角弧线：废材逆袭 + 升级流（混合型）
  - 核心谎言：「我天生就是废物」
  - 真相：废物只是没找到本命 / 力量不能定义价值
  - 节奏锚点：第 5 章金手指 / 第 12 章首次打脸 / 第 30 章金丹境对照场景
- 每次大突破必须配一个"开篇情境复刻"的对照选择
# 教训
- 废材期拖到 25 章读者跑光，已修；以后开篇蓄势压在 8 章内
""")
```

## 输出落点

本 skill 是**诊断 + 引导**型——主要产物是对话里的分析、追问、修复建议。
**不直接写 knowledge/**（那是 wiki-ingest 的独占地盘，见 story-collaborator
R3 同条约束，跨 skill 写入会破坏 wiki 一致性）。

需要跨会话持久的内容，按三档分流：

### A. 弧线设计决策 → `work_memory` 工具（写 MEMORY.md）

跟作者敲定的"这个角色就是这条弧线"属于**作品级约定**——下次开新对话、
另起 subagent、隔几天回来续写，弧线设计都还在。用 `work_memory` 工具
追加到 MEMORY.md 的 `# 约定` 段：

```
work_memory(action="add", content="""
# 约定
- 主角弧线：废材逆袭（正向变化）
  - 核心谎言：「我天生就是废物」
  - 真相：废物只是没找到本命兵种
  - 想要：血鳞剑（外部目标）
  - 需要：承认师父牺牲（内在转变）
  - 节奏锚点：第 5 章金手指 / 第 12 章首次打脸 / 第 30 章遭遇真强敌
""")
```

**该写到 MEMORY.md**：

* 弧线类型识别（"沈砚走平坦弧线，不接受改变只验证真相"）
* 核心谎言/真相对子
* 想要 vs 需要的差距锚点
* 网文弧线类型 + 关键节奏锚点（"主角走废材逆袭，第 5 章金手指，第 12 章首次打脸"）
* 反复确诊的状态警告（"A4 已 3 次出现「被打一顿突然顿悟」，禁止再用"）

**不要写到 MEMORY.md**：

* 一次性的诊断细节、追问过程、原文引用（留对话即可）
* 角色外貌/年龄/关系/技能等事实——那是 entities/<slug>.md 的内容，
  由 wiki-ingest 在章节定稿后自动沉淀
* 跨作品的作者偏好（"用户喜欢短句"）——那是全局 memory.json 的层

**5000 字符硬上限**——超额时先 `work_memory(action="remove", content=<旧条目>)`
再 `add`。删旧条目用整段精确匹配。

### B. 角色档案最终定稿 → 不动手

人物固化设定（最终人格、关系网、能力）在章节里被作者真正写出来后，
**wiki-ingest 会自动沉淀**到 `/mnt/user-data/knowledge/entities/<slug>.md`。
本 skill **不**直接 `write_file` 到 knowledge/——把这层完全留给 wiki-ingest。

要核对"作者写出来的角色"和"原计划的弧线"是否还吻合？让 LLM
`read_file /mnt/user-data/knowledge/entities/<slug>.md`，对照
MEMORY.md 里的弧线设计来诊断；不要试图反向把诊断结论写回 entities 页。

### C. 长草稿 / 多角色对照表 → workspace

如果一次设计会话产出了角色弧线对照矩阵、节奏甘特图、多版本草稿
（>500 字、属于"中间产物"而非"作品级约定"），写到：

```
write_file("/mnt/user-data/workspace/arcs-<slug>.md", <内容>)
```

workspace 里东西不进 wiki，作者随时可丢，也不会出现在 `<work_memory>`
注入块里——纯草稿区。

### 对话与文件

| 写到 MEMORY.md（work_memory） | 留在对话中     | 写到 workspace |
| ------------------------- | --------- | ----------- |
| 弧线类型 + 核心谎言/真相            | 澄清性追问     | 多角色弧线对照矩阵   |
| 想要 vs 需要差距锚点              | 选项讨论      | 节奏甘特图（长）    |
| 关键节奏锚点（"第 8 章打脸"）         | 单次诊断追问细节  | 多版本草稿       |
| 反复确诊的状态警告（防重蹈覆辙）          | 写作者的探索过程  |             |

## 集成

下游 skill 自动通过 system prompt 里的 `<work_memory>` 注入块看到本 skill
写入 MEMORY.md 的弧线设计——不需要额外的握手协议、不需要主动 read_file。
这是平台原生的"四层记忆"机制（见系统注入的 `<four_memory_layers>` 表）。

### 入站（什么场景会触发本 skill）

| 来源              | 信号                                                              | 本 skill 的反应                                              |
| --------------- | --------------------------------------------------------------- | -------------------------------------------------------- |
| wiki-ingest（反向回路） | `read_file /mnt/user-data/knowledge/entities/<slug>.md` 看作者实际写出来的角色 | 对照 MEMORY.md 里的弧线计划，检测偏离                                 |
| work-setup      | SOUL.md 的作品基调（"残酷写实"/"爽文"/...）                                  | 弧线类型选择受基调约束（残酷写实易走负向 / 爽文易走废材逆袭）                         |
| 作者直问            | 写新章前的"主角到底是怎样的人"                                                | 锁谎言/想要/需要/真相，写进 MEMORY.md `# 约定`                         |

### 出站（下游怎么用本 skill 的产出）

| 下游 skill          | 它从 `<work_memory>` 块里看到什么后能做什么          |
| ----------------- | ------------------------------------- |
| dialogue          | 弧线类型 + 节奏锚点章节号（dialogue 用当前章节号自行推断节拍位置）→ 决定语气漂移和潜台词浓度 |
| scene-sequencing  | "想要 vs 需要" 差距 → 场景级冲突的天然驱动力           |
| endings           | 真相 / 关键节拍章节号 → 高潮设计参照                |
| chinese-novelist  | 网文弧线类型 + 节奏锚点 → 章节节奏校准                |

### 互补

| 技能                   | 关系                                            |
| -------------------- | --------------------------------------------- |
| cliche-transcendence | 避免套路化的弧线类型和默认转变路径                             |
| work-setup           | 弧线选择必须呼应 SOUL.md 的基调和红线（"幽灵/创伤" 要在 SOUL.md 世界观字段说得通） |
