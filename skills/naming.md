
# Naming：中文网文命名

## 调用时机

- 用户说"起个名字 / 这个角色叫什么 / 招式叫什么 / 法宝叫什么"
- 用户主动 `/name <类型>` 命令（如 `/name 招式`）
- `work-setup` 收集主角姓名时主角没名
- `chapter-planner` 设计单章纲时新出场角色无名

> **网文命名是大事**。一个"张伟李娜"或"风影斩·终焉"两极的命名能毁基调。

---

## 命名类型矩阵

### 1. 角色名

#### 1.1 中式角色名

**基本原则**：

| 题材 | 风格 | 示例 |
|---|---|---|
| 修真 / 玄幻 / 仙侠 | 古风、单姓单名 / 双名 | 林尘、苏沐雪、叶清雪 |
| 武侠 | 古风、可三字、可加字号 | 萧逸、谢无尘、令狐冲 |
| 都市 | 现代日常 | 陈泽、林子昂、李宛清 |
| 历史 | 时代符合（避免现代化） | 周延儒、张居正风格 |
| 末世 / 科幻 | 简洁，可带洋气 | 江晚、洛书、艾伦 |
| 言情 | 唯美 / 干净 | 顾衍、沈知意、苏晚晴 |

**避坑**：
- 不要用太生僻字（"龘鱻"读不出来）
- 不要主角配角同姓（"林尘"配"林雪"会读者混乱）
- 不要名字情绪化过头（"林无敌"听着假）
- 男主名忌"软"（避免"沐辰、初染"等偏言情味）
- 女主名忌"硬"（避免"赵铁柱式"）

**命名公式**（仅供启发，不强制）：

```
姓 + 自然意象（尘 / 风 / 月 / 雪 / 川 / 渊 / 霖）
姓 + 品德/志向（清 / 正 / 怀瑾 / 守拙）
姓 + 古意（玄 / 衍 / 寒 / 霁）
```

#### 1.2 西式角色名

按目标读者熟悉度选：
- **常见洋名**（亚瑟、艾莉森、莱昂）= 易记
- **小众洋名**（瑟瑞迪斯、伊蕾娜）= 异域感
- **拉丁/希腊词根**（Aurelius / Cassiopeia）= 高级感

#### 1.3 反派名

反派名不要写得**一看就是反派**："魔尊冥煞"=脸谱化。优秀反派名应**有人味或诗意**：
- 高级感反派：玄机子、宋怀玉、慕容昭
- 阴狠感反派：周霁川（看似温润，实则阴险）

---

### 2. 招式 / 功法 / 法术名

**核心：意象 + 动词 / 意象 + 形容**。不要堆砌四字成语。

#### 2.1 修真招式（4 种风格）

| 风格 | 公式 | 示例 |
|---|---|---|
| **古典诗意** | 双字意象（动+静、自然+情感） | 落霞惊鸿、踏月斩、寒江雪 |
| **大气磅礴** | 单字 + 字数控制 | 万剑诀、九霄破、天倾 |
| **冷峻简洁** | 2-3 字白描 | 斩、归一、剑断 |
| **典故化** | 化用古诗词 | 折戟沉沙、长河落日 |

**避坑**：
- 招式 ≤6 字（"无极玄阴混沌湮灭神光"=灾难）
- 不要每招都"·终焉""·至尊""·无敌"
- 同一人物的招式系列要**有共同意象**（用"剑"系的别突然冒出"火"系）

#### 2.2 西幻法术

- 古英语 / 拉丁词根：Lux Aeterna（永恒之光）、Tempus Frangere（时间裂痕）
- 中译策略：**音译 + 意译双行**——"卢克斯·永恒之光"

#### 2.3 武侠招式

历史感、动作感为主：旋风脚、玉女剑十三式、降龙十八掌（已用，仅举例）

---

### 3. 法宝 / 道具名

**3 种风格**：

| 风格 | 公式 | 示例 |
|---|---|---|
| **材质 + 用途** | "玄铁剑、紫金钵、青铜鼎" |
| **意象 + 形 / 类** | "落星锤、断魂幡、引魂铃" |
| **典故化** | "诛仙剑、轩辕剑、东皇钟" |

法宝档次升序：凡品 → 法器 → 宝器 → 灵器 → 仙器（视体系而定）

---

### 4. 地名

**避坑**：不要全用东南西北 + 万 / 极 / 至（"极北万古玄冰渊"=俗）

**好用模板**：

| 类型 | 模板 | 示例 |
|---|---|---|
| 自然地形 | 山名 + 自然 | 青云山、苍梧岭、寒霜谷 |
| 人文 | 地名 + 历史 | 望江楼、问鼎台、洛阳城 |
| 神话 | 古词 + 仙气 | 蓬莱、瀛洲、九重天 |
| 异界 | 音译 + 意译 | 阿斯特利安、暗影荒原 |

---

### 5. 门派 / 势力名

**3 字最佳**："青云宗、玄天阁、万剑门"

避坑：
- 不要"宇宙最强 X 大宗门"——看着廉价
- 不要给好人门派"魔" / "邪" / "幽"开头（误导读者）
- 反派宗门也不要明晃晃叫"血煞门"——优秀反派宗门叫"九幽"反而更有味

---

### 6. 招式系列命名（常被忽视）

主角的招式集合应**有命名共同点**：

- 系列前缀："青云剑·" + 各招（青云剑·破云、青云剑·归一）
- 共享意象：所有招都用"风"字（追风、御风、断风）
- 数列编号："剑七式之一 / 之二 / 之三"

## 流程

### 第 1 步：识别命名对象 + 题材

从用户上下文识别：要起的是**人 / 招 / 物 / 地 / 派**？目标作品的**题材是什么**（看 SOUL.md）？

### 第 2 步：给候选清单（3-5 个）

不要只给 1 个。给 3-5 个备选 + 简短理由：

> 用户："给反派起个名"
> 你：
> 1. **玄机子**（青云宗宗主，高深莫测，看似仙风道骨实则深谋远虑）
> 2. **宋怀玉**（世家公子型反派，温润如玉但心狠手辣）
> 3. **周霁川**（书生反派，化用"霁后川流"意境，看似清雅实则阴沉）
>
> 我倾向 #1，符合 SOUL.md 里"宗门内部权斗"的反派定位。

### 第 3 步：交叉检查重名 / 重音

```
grep -l "name: <候选>" knowledge/entities/*.md
grep -l "aliases:.*<候选>" knowledge/entities/*.md
```

避免和已有角色撞名。

### 第 4 步：用户选定后，落档

- **角色名**：等 wiki-ingest 在该角色第一次出现时沉淀
- **招式 / 法宝**：作为概念由 wiki-ingest 沉淀到 `knowledge/concepts/`
- **地名**：sink 到 `knowledge/locations/`
- **门派**：sink 到 `knowledge/entities/`（type: faction）

本 skill 不直接写 knowledge/，只输出候选 + 用户选择记录到 `memory/decisions.md`。

## FAQ

**Q1：用户说"随便起一个"，怎么办？**
A：仍然给 3 个候选 + 默认推荐。不要直接给 1 个名硬塞——名字会在书里出现几百次，必须让用户参与决定。

**Q2：取的名后来用户不喜欢想改怎么办？**
A：调 `revision` L1（如果只在 1-3 章出现）或 L4（如果出现超过 10 章）。改名后**必须**全文 grep 替换并更新 wiki frontmatter aliases 加旧名。

**Q3：英文翻译怎么处理？**
A：本 skill 不做翻译。本作品语言固定（看 SOUL.md），中英混用避免。

**Q4：用户给的名违反命名原则（太长 / 撞名 / 风格不符）怎么办？**
A：提醒一次，但**最终听用户的**。用户审美主权 > skill 规则。

**Q5：能不能批量起一批配角名？**
A：能。但建议**用到时再起**——一次起 20 个名字，用户记不住，写起来配角混乱。
