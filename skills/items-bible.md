# items-bible · 关键物品档案（立项 ④b）

> 立项硬闸门 stage 4 的第二份资产：开篇 ~10 章会出现的「关键物品」（金手指、信物、法宝、亲人遗物等）逐个建档。
> 目的：避免在第 5 章突然冒出一件"祖传神器"或"师门禁地铜镜"还得回头补设定。

## 何时启用

- 用户说"立物品 / 道具 / 法器 / 物品表 / 金手指 / 关键道具 / 神器"等。
- 或 `locations-bible` 已完成（≥3 个地点档案）但 `knowledge/items/*.md` < 1 时，自动挂载。

## 必读前置

- `SOUL.md`：核心冲突 + 主角金手指的设定方向
- `knowledge/world/power-system.md`：力量体系（决定物品品阶上限）
- `knowledge/world/rules.md`：世界硬规则（哪些物品被禁、哪些会反噬）
- `knowledge/entities/<protagonist>.md`：主角的初始资源
- `knowledge/locations/*.md`：物品的"出生地"应该已经在地点档案里被预留

## 必调工具

- `read_file`：读完上面 5 类前置
- `ask_user`：物品对剧情影响极大，每写完一个就和用户敲定
- `wiki_ingest`：落档到 `knowledge/items/<item-slug>.md`
- `lookup_rebuild`：写完后重建索引
- 推荐 `conflict_check`：物品规则与世界规则是否冲突（关键反噬/代价）

## 禁用工具

- `write_chapter`、`write_outline`：物品没建完，禁止写正文/卷纲

## 输出要求（每个物品档案）

文件名：`knowledge/items/<slug>.md`。

```markdown
# <物品中文全名>

- **type**：信物 / 法器 / 功法 / 灵药 / 凶兽内丹 / 亲人遗物 / 任务道具 / ...
- **power_tier**：凡品 / 低 / 中 / 高 / 禁外 / TODO（与 `power-system.md` 对齐）
- **owner_now**：当前持有者（人物名 / 主角 / 暂未现身）
- **owner_history**：起源-中转-当前
- **first_chapter**：约第 X 章首次出现
- **price**：获取代价 + 反噬代价（**必填**，避免无成本金手指）

## 起源
- 由谁打造 / 自然产生 / 古遗留
- 与世界历史的连接（呼应 `world/history.md`）

## 效果与限制
- 主动效果：能做什么
- 被动效果：携带后的常态影响
- 触发代价：寿命/灵力/精神/情感
- **硬限制**：不能做什么、不能在什么场合用、被什么克制

## 在主线中的跟踪
- 第 X-Y 章作用：……
- 升级/进化条件：……
- 失去/损坏的剧情节点（若有）：……

## 视觉与触感
- 让读者一眼记住的特征：颜色、形状、纹路、温度、声音、气味
```

## 数量与节奏

- **至少 1 个**物品档案才能进入下一阶段（硬闸门）
- 主角金手指/核心信物**必须有档案**——这是开篇 5 章绕不开的
- 推荐 3-10 个；超过 10 个考虑是否有些只该是消耗品而不必建档

## 退出条件（exitWhen）

- `knowledge/items/*.md` 文件数 ≥ 1
- 每个文件都至少包含 `## 效果与限制` 和 `price` 字段
- `lookup_rebuild` 成功，物品条目可被 `lookup_query` 找到

## 常见错误

- ❌ 把"宝物清单"做成 50 行 Excel 表，没人物连接、没代价 → 不算档案，重写
- ❌ 给主角金手指设"无代价" → 写到第 10 章必崩
- ❌ 物品名重复或与人物名混淆 → `conflict_check` 会报，请改名

## 与下游 skill 的衔接（chainsTo）

完成后链到 `outline-collaborator`：地点 + 物品 + 人物全部就位，可以开始写**总纲**了。
