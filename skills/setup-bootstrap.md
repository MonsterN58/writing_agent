# Setup-Bootstrap：立项前的风格基线启动器

## 调用时机

- 用户首次新建作品（`SOUL.md` 不存在），且尚未上传任何参考样本
- 用户主动说："先帮我把文风定下来 / 我想模仿 XX 风格 / /style-bootstrap"
- 写第 1 章前发现 `style/voice.md` 还是空（或与作品类型不匹配）
- 已写 ≥ 3 章但用户反馈"文风不稳"，并且确认要重置基线

> **设计动机**：真人网文作者动笔前都有"案头预读"——重读 1-2 部目标读者群已认可的同类作，把节奏/口吻/钩子密度调到对的频道，再开写。AI 跳过这步直接开写，前 3 章往往就崩，回头再补 voice.md 已经污染了前几章。

---

## 核心任务

通过最多 3 轮对话，把作者脑子里"我希望读起来像谁"转译成两份长期资产：

1. **`style/voice.md`** — 一段话风格基准 + 句长节奏 + 感官偏好 + 对白风格 + 反 AI 味禁令（配合 `style-voice` skill）
2. **`style/voice-dict.md`** — 高频词典 + 禁用词典 + 句式偏好（运行时由后端按需注入到写章 prompt）

后续写章时，`get_chapter_context` 会自动读取这两个文件并注入 system prompt，让所有章节落在同一频道。

## 流程

### 第一步：询问启动方式（**首步必做**）

调 `ask_user` 让用户选择三种启动方式之一：

```
ask_user({
  question: "我们先把文风基线定下来再开写。你倾向哪种方式？",
  options: [
    "A. 我贴 1-3 段我喜欢的网文/小说片段，你来抽风格指纹（推荐，最准）",
    "B. 我用文字描述我想要的风格（如：紧凑短句 / 黑色幽默 / 散文化）",
    "C. 用默认基线（爽文中等节奏 + 反 AI 味底），写完前 5 章再调"
  ],
  context: "三种方式都会落盘 style/voice.md + style/voice-dict.md，区别是精度。A 最贴你心里的样子；B 中等；C 兜底。"
})
```

**根据用户选择：**

| 选 | 路由 | 后续 |
|---|---|---|
| A | 进入「第二步 · 样本抽取」 | 用户贴样本后由本 skill 抽风格 |
| B | 进入「第三步 · 描述抽取」 | 用户描述后由本 skill 转译 |
| C | 进入「第四步 · 默认兜底」 | 直接写默认 voice.md + 空白 voice-dict |

如用户上来就贴 ≥800 字的长文本，按 **A 路由**直接进入第二步。

如用户已经在前面对话里描述过风格（"我想要古龙那种短句、不抒情"），按 **B 路由**直接进入第三步。

---

### 第二步：样本抽取（A 路由）

让用户连续贴 1-3 段参考样本（每段 200-2000 字），然后做以下抽取：

#### 2.1 句长分布
- 取最长 5 句、最短 5 句、中位句长
- 判定基调：**短句驱动**（中位 ≤ 18 字）/ **中长句**（19-32）/ **长句散文化**（≥ 33）

#### 2.2 段落密度
- 每段平均句数（1-2 / 3-4 / ≥5）
- 段间留白：是否每场景一空行

#### 2.3 高频词（≥ 3 次出现，去掉超常用助词）
- 提取 10-20 个特征词，按词频排序
- 这些词是作者的"声音签名"，写章时**应延续使用**，避免突然换同义词造成"突然换人"

#### 2.4 禁用词（用户讨厌或样本中明确没有的）
- 询问用户："样本里**没有**出现但其他网文常见的 AI 味词，要不要加进禁用？" 列默认 10 个让用户勾选
- 默认候选：心潮澎湃、热血沸腾、不由得、深吸一口气、瞳孔骤缩、嘴角微微上扬、命运的齿轮、原来如此、仿佛整个世界、一道道目光

#### 2.5 对白风格
- 主角是简短利落 / 文绉绉 / 口语化 / 带方言？
- 配角声音是否分化？（避免所有角色一种书面腔）

#### 2.6 钩子偏好
- 样本章末是 **危机钩**（被截击）/ **信息钩**（揭谜底）/ **情绪钩**（决意/告别）/ **反转钩**（敌人是友）哪种为主？

#### 2.7 修辞偏好
- 比喻密度（高/中/低）
- 心理描写比例（动作泄露 vs 直白心声）
- 感官层（视觉为主 / 听觉触觉并重 / 气味突出）

把上述抽取结果**用一段自然语言复述**给用户：

> 例："我从你贴的 3 段样本里抽出来的样子是：
> - 短句驱动（中位 14 字），段落 1-3 句换行密
> - 高频词：剑、刀、风、雪、夜、影、刃、冷、寒（武侠/古风的物件签名）
> - 禁用：所有"心潮澎湃 / 不由得 / 嘴角微微上扬"类词
> - 主角说话简短，配角分化（女性书生气、武林粗豪）
> - 章末偏**危机钩**和**情绪钩**，少用反转
> - 比喻偶用、心理靠动作泄露、视觉听觉并重
>
> 这是你想要的样子吗？要改哪一项？"

用户认可（或修正后认可）后，进入「第五步 · 落盘」。

---

### 第三步：描述抽取（B 路由）

让用户用 100-300 字描述目标风格。例：
> "我想要短句、不抒情、对话推动剧情、像古龙武侠又带点黑色幽默。"

按用户描述，**主动配置**以下字段：

| 字段 | 从描述推断 |
|---|---|
| 句长 | "短句" → 短句驱动；"散文化/抒情" → 长句 |
| 抒情密度 | "不抒情/克制" → 低；"细腻/温暖" → 中；"史诗/磅礴" → 高 |
| 对白比例 | "对话推动" → 30-45%；"心理为主" → 10-25% |
| 钩子偏好 | "悬疑" → 信息+反转；"武侠/玄幻" → 危机+情绪 |
| 高频词 | 从用户给出的题材猜测（武侠 → 剑/刃/风/雪；都市 → 街/灯/夜/雨；玄幻 → 灵气/丹/符/玄） |
| 禁用词 | 默认 AI 味全集 + 用户描述里反对的词 |

复述配置 + 让用户兜底确认（"你说像古龙我就配了短句 + 危机钩 + 武侠物件高频词，对吗？"），进入「第五步 · 落盘」。

---

### 第四步：默认兜底（C 路由）

若用户选 C，写一份**中性默认基线**：

- 句长：中句为主（中位 22 字）
- 段落：1-3 句/段
- 高频词：留空，由作者自己写章后由 `style-voice` 重新统计
- 禁用词：注入完整 AI 味默认 35 项（同 `style-voice.md` 模板）
- 对白：主角具体度待定，配角分化标记开启
- 钩子偏好：危机+情绪+信息均衡

**强提醒用户**：
> "默认基线只是兜底。建议你写完前 5 章后**主动调一次 `/style`**，让我从你已经写出来的章节里反向提取真实风格指纹。这是大多数作者的真实做法。"

进入「第五步 · 落盘」。

---

### 第五步：落盘

调 `update_progress` 写两份文件：

#### 5.1 `style/voice.md`

按 `style-voice` skill 的模板写入完整版，**重点字段从前面抽取的结果填**：
- "一句话基准"段：用第二/三步复述给用户的那句话
- "句式节奏"段：填入抽取到的句长分布、段落密度
- "感官与画面"段：填入感官偏好
- "对白"段：填入主配角分化偏好
- "反 AI 味禁令" 段：保留默认 35 项，再加用户特别强调的禁用词
- "章末钩子偏好"段：填入抽取到的钩子分布

#### 5.2 `progress/pre-read.md`（**仅 A 路由用户必写**，B/C 路由可跳过）

新建文件，把用户贴过来的样本**按 200-500 字摘要 + 来源标记**存档，作为长期"风格预读资产"。写章时 `get_chapter_context` 会读取并注入到 system prompt。

```markdown
# 风格预读样本（作者参考作品摘要）

> 这是作者在 setup-bootstrap 阶段提供的 1-3 段参考作品摘要。
> 写章时由 get_chapter_context 自动注入，作为风格指南的**正面范本**。
> 不要照抄文字，是用来对齐"质感"和"节奏"的。

## 样本 1
- **来源**：<用户标注的来源，如：古龙《多情剑客无情剑》第三章 / 网文《某仙逆》第 12 章 / 自己以前的章节>
- **摘要**：<200-500 字摘要，保留原文的句长节奏和高频词，不要 paraphrase 成抽象描述>

## 样本 2
- **来源**：...
- **摘要**：...

## 样本 3
- **来源**：...
- **摘要**：...
```

> ⚠️ 不要把整段原文一字不漏存进来（版权风险 + token 浪费）。**保留风格质感的代表段落即可**。如果用户贴的样本本身就 ≤ 500 字，可以全文存档。

#### 5.3 `style/voice-dict.md`

新建文件，结构如下：

```markdown
# 作者高频词典与禁用词典（自动维护，可手改）

> 此文件由 setup-bootstrap 初始化，写章后由 style-voice 增量更新。
> 后端 get_chapter_context 在写章时自动读取本文件并注入 system prompt。

## 高频词（"声音签名"，写章时优先延续）

剑 · 刃 · 风 · 雪 · 夜 · 影
（按词频排序，前 20 个）

## 禁用词（"AI 味闭眼写也不能用"，出现一个算违章）

心潮澎湃 · 热血沸腾 · 心头一震 · 复杂的情感 · 五味杂陈
不由得 · 忍不住 · 深吸一口气 · 瞳孔骤缩 · 脸色一变
握紧拳头 · 咬紧牙关 · 嘴角微微上扬 · 嘴角勾起一抹 · 眼神坚定
眼神复杂 · 眸光闪烁 · 不动声色 · 骤然 · 霎时
刹那间 · 千钧一发 · 与此同时 · 命运的齿轮 · 前所未有
原来如此 · 现在看来 · 真相只有一个 · 一切都说得通了 · 仿佛整个世界
仿佛连空气都凝固了 · 仿佛时间都静止了 · 一道道目光 · 全场寂静 · 鲜血从嘴角溢出

## 句式偏好

- 句长中位：14 字
- 段落密度：1-3 句/段
- 比喻密度：低（每千字 ≤ 2 个）
- 章末禁用：破折号、省略号、单字独立成段

## 对白配方

- 主角：简短利落，少书面腔
- 配角声音分化：开启
- 禁止所有角色同种文人腔

## 钩子偏好

- 危机钩：40%
- 情绪钩：30%
- 信息钩：20%
- 反转钩：10%
```

> 这两份文件**写完后立即可生效**，下游 `chinese-novelist` 写第 1 章时由 `get_chapter_context` 自动读取并注入。

### 第六步：移交

落盘完成后，**告诉用户**已完成的事 + 下一步要做什么：

> "好。文风基线建好了：
> - `style/voice.md`（写章前自动注入）
> - `style/voice-dict.md`（高频词 / 禁用词 / 句式偏好）
>
> 接下来按计划走：
> 1. ✅ 文风基线（刚完成）
> 2. SOUL.md 作品宪章 ← 下一步
> 3. 世界观 / 人物 / 总纲 / 卷纲 / 细纲（共 5 步）
> 4. 第 1 章正文
>
> 继续走 SOUL 立项？"

- 用户说"继续/搭设定/立项" → 移交 `work-setup`
- 用户说"我先聊聊剧情" → 移交 `story-collaborator`
- 用户说"直接开写" → 强提醒"SOUL 还没立，开写会很危险"，确认后再让 `chinese-novelist` 接管

## FAQ

**Q1：用户没提供任何样本，也不愿描述风格，怎么办？**
A：走 C 路由（默认兜底）+ 强提醒写完前 5 章后回头跑 `/style`。本 skill 不强求精准，求"先有个底"。

**Q2：用户贴了一段超长（>5000 字）的样本，怎么办？**
A：抽样本前 1500 字 + 后 500 字做指纹分析，告诉用户"我看了开头和结尾这部分"。整段全嚼太费 token。

**Q3：用户的样本是 AI 写的，会不会把 AI 味当成风格学进去？**
A：会！要在抽取时**主动识别**：如果样本里出现 ≥ 3 个默认 AI 味禁用词，警告用户"这段样本本身有 AI 味，不建议作为基线，要换一段吗？"用户坚持则照抽，但禁用词列表只在用户明确允许时才"放开"。

**Q4：作品已经写了 N 章想换风格，能调本 skill 重置吗？**
A：可以但要警告："已写章节不会自动重写，新基线只对未写章节生效，前后章可能有割裂感。" 用户确认后覆盖 `style/voice.md` 和 `style/voice-dict.md`，并在 `memory/decisions.md` 记一笔。

**Q5：本 skill 与 `style-voice` 的边界？**
A：
- `setup-bootstrap`（**本 skill**）= **冷启动**，从 0 建立基线，必经 ask_user 路由（A/B/C）
- `style-voice`（[`@/skills/style-voice.md`]） = **运行时调整**，从已写章节反向统计，**不**问 A/B/C
- 两者都写 `style/voice.md`；前者还写 `style/voice-dict.md`；后者**只更新**已存在的 voice-dict。

## 反面禁忌

- ❌ 不要跳过 ask_user 直接写默认 voice.md（那是 C 路由的事，不是默认动作）
- ❌ 不要在第二步把样本嚼成 5000 字的指纹报告——只要 200 字以内的复述就够
- ❌ 不要把"高频词"和"禁用词"混到同一列表
- ❌ 不要在 voice-dict.md 里堆 100+ 个高频词——只取最有签名感的 15-25 个
- ❌ 不要因为用户没回答完所有问题就卡住，**默认值兜底**继续推进
