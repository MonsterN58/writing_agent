
# Webnovel-Tropes：网文爽点设计

## 调用时机

- 用户说"再爽一点 / 这章不够爽 / 加点装逼桥段"
- 用户主动 `/tropes` 命令
- `chapter-planner` 判定本章拍位是「爽」时自动链
- 写"扮猪吃虎 / 打脸 / 系统流"专属桥段时

> **本 skill 和 `cliche-transcendence` 互补**：本 skill 教**怎么用爽点**（爽点是网文骨架），后者教**怎么不烂俗**（同一个爽点的高级写法）。

> ⚠️ **使用纪律**：每个爽点矩阵下都有对应的「反套路对偶」段。**调用本 skill 时必须同时读对偶段**，避免 LLM 把套路本身当成目标，生成「越被低估反杀越爽 → 反派每次嘴贱 + 主角每次秒杀」这种纯模板化情节。
>
> 反套路 ≠ 不用套路。反套路 = 用套路的骨架 + 反期待的细节 / 道德灰度 / 真实代价。

## 网文爽点矩阵

### 一、金手指（主角的优势源）

主角必须有**至少一个金手指**，但金手指要**有限制、有代价**才不烂俗。

| 类型 | 示例 | 限制设计 |
|---|---|---|
| **传承流** | 上古传承 / 失传功法 | 修炼条件苛刻 / 副作用 |
| **系统流** | 系统签到 / 任务奖励 | 任务难度递增 / 失败惩罚 |
| **重生流** | 重生回到关键节点 | 蝴蝶效应 / 知识有边界 |
| **穿越流** | 现代知识降维打击 | 知识水土不服 / 古代规则约束 |
| **血脉流** | 远古血脉觉醒 | 觉醒条件 / 血脉反噬 |
| **天赋流** | 灵根 / 体质特殊 | 招敌 / 早期吃瘪 |
| **奇遇流** | 偶得宝物 / 偶遇高人 | 宝物有主 / 高人考验 |
| **复合流** | 系统 + 重生 / 传承 + 血脉 | 复杂度 ↑，难驾驭 |

**设计原则**：
- 一个核心金手指 + 1-2 个次级辅助，**不要叠 4 个以上**（叠太多 = 没限制 = 没张力）
- 金手指必须**有代价**（消耗寿元 / 触发追杀 / 升级有阈值）
- 金手指**不能全程无敌**——前期必须有 2-3 章吃瘪期，让读者期待爆发

### 二、装逼节奏（4 步公式）

经典装逼桥段四步：

```
1. 反派低估（"就你？也敢挑战我？"）
   ↓
2. 主角藏拙（不露真实修为，言语谦卑或反讽）
   ↓
3. 反派炸毛（自取其辱，越骂越凶）
   ↓
4. 主角亮招（一击碾压，全场寂静）
```

**装逼时间预算**：
- 短装逼：300-500 字（一个场景内完成）
- 中装逼：800-1200 字（两个场景，第一场景被低估，第二场景反杀）
- 长装逼：2000+ 字（整章铺垫，章末爆发）

**装逼禁忌**：
- 不要每章都装逼（疲劳）
- 不要一开口就嚣张（应先藏拙再露锋芒）
- 不要无来由装逼（必须有反派先挑衅）

**反套路对偶（避免纯模板化）**：
- ❌ 反派单纯嚣张 / 主角秒杀 / 围观倒吸冷气：纯模板，写多了 LLM 自动出现「全场寂静 / 一道道目光投向 / 仿佛连空气都凝固了」AI 套路
- ✅ 反派有动机：他嚣张是因为家族压力 / 误信情报 / 真有底牌
- ✅ 主角有代价：亮招暴露身份 / 损耗法宝 / 遭忌被记仇
- ✅ 围观者反应不写脸谱：写一两个具体路人的具体动作（茶碗端到嘴边没喝、伙计的算盘停了）替代群体性「倒吸一口气」
- ✅ 装逼留余地：主角赢得不彻底，反派还有翻盘资源，下次再交手

### 三、打脸桥段（5 种模板）

| 模板 | 触发条件 | 经典节拍 |
|---|---|---|
| **当面打脸** | 反派当众羞辱主角 | 主角默默承受 → 反派加码 → 主角一击秒杀 → 反派下跪求饶 |
| **隔代打脸** | 主角弱时被欺压，强后回去算账 | 翻篇时机：5-15 章后回去 |
| **打脸帮凶** | 反派身边走狗第一个被打脸 | 走狗先嚣张 → 主角随手干掉 → 反派失靠山 |
| **打脸长辈** | 长辈瞧不起主角 | 主角立功 → 长辈震惊 → 主动认错或被迫低头 |
| **群体打脸** | 一群人嘲笑主角 | 比试 / 拍卖会 / 宴会 → 主角一鸣惊人 → 全场倒吸冷气 |

**打脸的爽感来源**：
- **反差越大越爽**（越被低估，反杀越爽）
- **节奏越紧凑越爽**（铺垫不要超过 1000 字）
- **反派越嚣张越爽**（让反派蹦得高一点再砸下来）

**反套路对偶（避免脸谱化打脸）**：
- ❌ 反派纯坏 / 主角全对 / 反派下跪求饶：脸谱戏，读者麻木
- ✅ 反派有自己的逻辑：他羞辱主角是因为之前主角伤过他兄弟 / 他在执行家族令 / 他自己也是棋子
- ✅ 主角打脸不止"打"：除了赢，还要展示主角对这件事的复杂反应（厌恶 / 失望 / 早该如此）
- ✅ 反派下场不必下跪：被打脸后保持骨气、继续敌对、暗中报复，比立刻下跪精彩
- ✅ 读者感受不止爽：读者看到反派也有可怜处时，爽感会从单纯的胜利变为更复杂的情绪——这才是耐读的打脸

### 四、扮猪吃虎

**核心**：主角**主动隐藏实力**让对方误判，再一击爆发。

经典桥段：
- 入门考核故意装废 → 后期觉醒打脸
- 衣着朴素让人误以为穷酸 → 拍卖会一掷千金
- 自称"过路人"被人刁难 → 真实身份是大宗师

**扮猪吃虎写作要点**：
- 主角**自己知道**自己强（不是真废逆袭，那是另一个套路）
- 给读者**视角内信息差**——读者也跟着主角一起"扮猪"，最后一起"吃虎"
- 时长不要超过 5 章（太长读者会怀疑主角真的是废柴）

**反套路对偶（避免低智反派）**：
- ❌ 反派全员瞎眼 / 主角扮猪零代价：套路写久了人物全员降智
- ✅ 反派至少 1 个看出端倪：写一个聪明配角察觉主角不简单（但因身份 / 利益不揭穿），让读者紧张
- ✅ 扮猪有代价：主角藏拙意味着错过某些机会 / 不得不忍耐羞辱 / 误伤盟友
- ✅ 吃虎不必当众：低调收尾比"全场震惊"耐读——主角随手解决问题，反派事后才意识到

### 五、升级爽感（金字塔)

| 层级 | 爽感强度 | 频率 |
|---|---|---|
| 微爽（一个小目标达成） | ★ | 每章 1-2 次 |
| 中爽（境界 / 资源 / 关系突破） | ★★ | 每 3-5 章 1 次 |
| 大爽（一个阶段性目标完成 / 重要打脸） | ★★★ | 每 10-15 章 1 次 |
| 巨爽（一个弧光 / 一卷的高潮） | ★★★★ | 每 30-50 章 1 次 |

**升级节奏**：
- 不要让主角**连续多章不升级**——读者会失去期待
- 不要**刚升级就再升级**——爽感稀释，读者麻木
- 大爽和巨爽要**铺垫足够憋章**（憋 3 章爆 1 章）

**反套路对偶（避免数值通胀）**：
- ❌ 升级只为升级 / 越打越强 / 反派永远比主角弱半阶：纯数值游戏
- ✅ 每次升级**改变主角的处境**：境界突破让旧朋友疏远 / 实力增长招来新麻烦 / 资源到手却需还人情
- ✅ 升级不必赢：升级章可以是"突破后吃了一次大亏"，让读者意识到强大不能解决所有问题
- ✅ 中爽以上必带**伏笔推进**：每次中爽至少推进一条主线伏笔，避免"升级 → 打脸 → 再升级"的纯循环

### 六、系统流专属

**系统流**是网文最常见的金手指模板，单独说：

| 元素 | 设计要点 |
|---|---|
| **任务系统** | 主线任务（推剧情）+ 支线任务（撒爽点）+ 隐藏任务（埋伏笔） |
| **奖励梯度** | 经验 → 道具 → 功法 → 血脉 → 至宝（递进） |
| **签到 / 抽奖** | 每章/每周节奏点，给小爽 |
| **系统人设** | 高冷型 / 萌系 / 毒舌 / 贱兮兮——和主角性格反差 |
| **限制** | 任务失败惩罚 / 系统冷却 / 升级解锁 |

**系统流禁忌**：
- 系统不要全知全能（主角自主性消失）
- 任务奖励不能高于主角自身努力收益（否则读者觉得"开挂"过头）
- 系统不要随时跳出说话打断节奏（关键时刻才出现）

**反套路对偶（避免系统冗杂）**：
- ❌ 系统什么都管 / 任务一直推 / 奖励一直涨：系统反客为主，主角变工具人
- ✅ 系统**有它自己的目的**：任务背后有更大的设定阴谋（系统是谁造的？为什么挑中主角？）
- ✅ 系统**有失灵时刻**：关键章故意让系统失效 / 信号丢失 / 误判形势，逼主角靠自己
- ✅ 主角**怀疑过系统**：写一两章主角主动违抗系统指令，让人物有自主性
- ✅ 任务奖励**有不可见代价**：拿了奖励等于欠了某个未知主体的债，伏笔留给后面回收

### 七、桥段组合公式

经典网文章节常用以下组合：

```
开局：上章悬念延续 + 微冲突起手
中段：装逼 / 打脸 / 扮猪吃虎（选 1）
结尾：钩子（参 hook-and-cliffhanger）
```

或：

```
全章铺垫吃瘪（憋）
→ 章末瞬间反转（爽）
→ 钩子留下后续期待
```

## 流程

### 第 1 步：识别意图

用户说"加爽点"时，先问 1 个澄清问题（除非上下文已明确）：

> "你想要哪种爽？打脸 / 装逼 / 升级 / 还是综合一记？"

---

### 第 2 步：从矩阵选模板

按用户意图 + 当前章节拍位（chapter-planner 已定）选 1-2 个爽点模板组合。

---

### 第 3 步：检查冲突

调 `wiki-query` 确认：

- 反派人物状态是否合理（不能让一个上章被打脸的反派本章再来挑衅）
- 主角实力是否足够亮招（不要让"装逼亮招"和"实际修为"穿帮）
- 是否和 SOUL.md 红线冲突（用户红线"主角不黑化"则不能写黑化打脸）

---

### 第 4 步：把模板**写进单章纲**

不是直接写正文——本 skill 输出**爽点设计稿**，更新到 `outline/chapters/chapter-N.md` 的"场景节拍"段，再交棒 `chinese-novelist` 写正文。

## FAQ

**Q1：每章都装逼会不会过？**
A：会。装逼频率上限**每 2-3 章 1 次大装逼，每章可有 1 次小装逼**。频繁装逼读者会麻木。

**Q2：怎么和 cliche-transcendence 配合？**
A：本 skill 选模板，cliche-transcendence 优化模板写法。例如：用本 skill 选了"打脸长辈"，再用 cliche-transcendence 让长辈不要是脸谱化反派。

**Q3：用户说"我不想写爽文，想写严肃的"怎么办？**
A：本 skill 不强加。看 SOUL.md 基调字段，如果是"暗黑向 / 现实向 / 文学向"，本 skill 默认不触发，只有用户主动 `/tropes` 才介入。

**Q4：金手指设计完后怎么落盘？**
A：写到 `knowledge/concepts/<金手指 slug>.md`（由 wiki-ingest 在第一次出现时沉淀），不要本 skill 直接写。

**Q5：扮猪吃虎和废材逆袭区别？**
A：扮猪吃虎 = 主角**已经强**，主动装弱；废材逆袭 = 主角**真的弱**，靠机缘变强。两者节奏完全不同，不要混。
