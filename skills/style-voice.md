# Style Voice Anchor · 风格锚

> ⚠️ **与 [setup-bootstrap](setup-bootstrap.md) 的分工**：
> - `setup-bootstrap`（**冷启动**）= 在 `SOUL.md` 之前从 0 建立基线，必走 ask_user 三选一（A 样本 / B 描述 / C 默认）
> - `style-voice`（**本 skill**）= 写完 ≥ 3 章后从已写章节**反向统计**，更新已存在的 `voice.md` + `voice-dict.md`
>
> 两者都写 `style/voice.md`，但 setup-bootstrap 是"先验"，本 skill 是"后验"。

## 触发

- 用户要求：调文风 / 建立文风 / 风格锚 / voice anchor
- 当前作品写章质量不稳，需要一个长期声音基准
- 已写 ≥ 3 章，写章前的 voice 还是 setup-bootstrap 的兜底默认（C 路由），需要从真实章节升级
- `/style` 快捷命令

## 目标

产出/更新两份长期风格资产，作为后续 `get_chapter_context` 自动注入到写章 prompt 的锚：

1. **`style/voice.md`** — 一段话基准 + 句长节奏 + 感官偏好 + 对白风格 + 反 AI 味禁令
2. **`style/voice-dict.md`** — 高频词典 + 禁用词典 + 句式偏好（数据导向，便于运行时直接 grep）

## 流程

1. 先读：
   - `SOUL.md`
   - `style/voice.md`（如存在，作为升级前基线）
   - `style/voice-dict.md`（如存在，作为升级前词典）
   - `chapters/latest-draft.md`（如存在，maxChars=5000）
   - 最近 3 章正文（从 `list_chapters` 找到，每章读 5000 字）
   - `style/feedback.md`（如存在）
2. 反向统计真实风格：
   - **句长分布**：抽 200 个句子，算最短/中位/最长 + 标准差
   - **段落密度**：每段平均句数
   - **高频词**：去掉超常用助词后，统计 ≥ 3 次的特征词，取前 25 个；先过 AI 味黑名单，命中黑名单的词**禁止进入高频词**
   - **AI 味词检测**：从已写章节中检测出现过的 AI 味词（默认 35 项），如果有就**追加**到禁用词
   - **比喻/感官/对白比例**：抽样统计
   - **章末钩子分布**：危机/情绪/信息/反转 各占多少
3. **对比 setup-bootstrap 留下的基线**：哪些维度发生漂移？
   - 漂移 ≤ 20%：保留原基线
   - 漂移 > 20%：用真实统计覆盖，并在 `memory/decisions.md` 记一笔"风格 vN → vN+1"
4. **升级门禁**：
   - 只有当样本章 ≥ 3、且 AI 味命中率低于 2 次/千字时，才允许把高频词写入"声音签名"
   - 如果 AI 味命中率超标，`style/voice-dict.md` frontmatter 必须写 `polluted: true`
   - `polluted: true` 时只能更新禁用词、句长、段落密度、破折号/省略号上限，不能把章节里的高频词当成可模仿资产
   - 如果只是用户反馈要求"避雷某些词"，可只追加禁用词，不升级 voice 版本
5. 调 `update_progress` 写入：
   - `style/voice.md`（完整模板）
   - `style/voice-dict.md`（高频词 + 禁用词 + 句式偏好）

## `style/voice.md` 模板

```markdown
# 风格锚

## 一句话基准
<本作品应该读起来像什么>

## 叙述距离
- POV：<限制第三人称/第一人称/多 POV>
- 镜头距离：<贴身/中景/全知>
- 心理描写：<少抽象，多动作泄露>

## 句式节奏
- 常用句长：<短句/中句/长短交错>
- 段落密度：<每段 1-4 句>
- 转场方式：<动作/物件/声音/时间切口>

## 感官与画面
- 优先感官：<触觉/听觉/视觉/气味>
- 场景落点：<具体物件，不写空泛氛围>

## 对白
- 主角说话：<特点>
- 配角说话：<特点>
- 禁止所有角色同一种书面腔

## 反 AI 味禁令

### 禁用词（35+，闭眼写也不能出现，出现一个算违章）

**情绪占位词**：心潮澎湃、热血沸腾、心头一震、复杂的情感、五味杂陈、百感交集、不寒而栗、寒意涌上、寒光闪烁、不禁、忍不住、不由得

**反应表演词**：瞳孔骤缩、脸色一变、脸色骤变、握紧拳头、咬紧牙关、深吸一口气、嘴角微微上扬、嘴角勾起一抹、眼神坚定、眼神复杂、眸光闪烁、眼眸深邃、不动声色

**时间感叹词**：骤然、霎时、刹那间、千钧一发、与此同时（叙述衔接除外）

**报幕式陈词**：原来如此、现在看来、命运的齿轮、前所未有、这一刻他才明白、真相只有一个、一切都说得通了

**万能受伤 / 围观**：鲜血从嘴角溢出、嘴角溢出一抹血丝、抹去嘴角的血迹、全场寂静、所有人倒吸一口气、一道道目光（投向）、仿佛连空气都凝固了、仿佛时间都静止了

### 禁用句式

- 总结式鸡汤结尾（"这就是 / 原来 / 这一刻"）
- 抽象情绪解释（"心中涌起复杂的情感"——改用动作 / 物件透露）
- 章末开放式留白：「他选了——」、「月光下，他……」、「……」单独成段
- 「他握紧拳头」+ 任何会意动作 的双件套
- 三段式排比："不仅 X，更是 Y，甚至 Z"
- 三组顿号堆砌（"璀璨、瑰丽、绚烂"——网文很少需要）
- "如同 / 仿佛 / 像是" 比喻三连
- 所有角色同一种书面腔（"在下 / 阁下 / 不知尊驾"）

### 破折号与省略号密度上限
- "——" 每千字 ≤ 2 个，章末收束句禁用
- "……" 每千字 ≤ 3 个，禁用单独成段
- 章末**禁止**以破折号或省略号结尾

### 替代策略
- 情绪 → 用具体动作（手指搓桌沿、把茶倒了又添）+ 物件（伞偏半寸、灯灭一盏）+ 慎重台词透露
- 场景 → 视觉以外至少补一项：听觉 / 触觉 / 温度 / 气味
- 章末 → 用一件具体物件（蜡封、折扇、丹药匣）做收束钩点

## 章末钩子偏好
<信息钩/危机钩/情绪钩/反转钩如何使用>

## 用户反馈记忆
<从 style/feedback.md 汇总出的长期偏好>
```

## `style/voice-dict.md` 模板

```markdown
---
version: 1
source: setup-bootstrap|style-voice
polluted: false
sample_chapters: []
ai_hits_per_1k: 0
updated_at: <ISO 时间>
---

# 作者高频词典与禁用词典（运行时由 get_chapter_context 注入）

> 此文件由 setup-bootstrap 初始化，由 style-voice 在写完 ≥ 3 章后增量更新。
> 后端在写章时自动读取本文件并注入 system prompt 的 `<voice_dict>` 段。
> 若 frontmatter 中 `polluted: true`，后端仍会注入本文件，但写章时只允许参考禁用词/句长/段落限制，不得模仿"高频词"。

## 高频词（"声音签名"，写章时优先延续，避免突然换同义词）

<词1> · <词2> · <词3> · ...
（按词频排序，前 15-25 个）

## 高频词过滤记录

- 剔除 AI 味词：<心潮澎湃 / 不由得 / 嘴角微微上扬 / ...>
- 剔除泛词：<他 / 这个 / 只是 / 似乎 / ...>
- 本次是否污染：<false|true>

## 禁用词（出现一个算违章）

<禁用1> · <禁用2> · <禁用3> · ...
（默认 35 项 AI 味全集，外加从已写章节检测到出现过的"假违章"）

## 句式偏好

- 句长中位：<N> 字
- 段落密度：<N>-<N> 句/段
- 比喻密度：每千字 ≤ <N> 个
- 破折号密度：每千字 ≤ <N> 个
- 章末禁用：破折号 / 省略号 / 单字独立成段

## 对白配方

- 主角：<具体度，如：简短利落 / 文绉绉 / 口语化 / 带方言>
- 配角声音分化：<开启 / 关闭>
- 禁止所有角色同种文人腔

## 钩子偏好（从已写章节统计的真实分布）

- 危机钩：<N>%
- 情绪钩：<N>%
- 信息钩：<N>%
- 反转钩：<N>%
```

> ⚠️ **voice-dict.md 不是 voice.md 的复制版**——voice.md 是"行文哲学"段落式描述，voice-dict.md 是"可 grep 数据"。后端注入两者，写章模型既看到原则也看到具体清单。

## 交付

写完后简短告诉用户：
- 已建立/更新 `style/voice.md` + `style/voice-dict.md`
- 后续写章会由 `get_chapter_context` 自动注入两份文件
- 用户可以继续用预览页反馈按钮更新 `style/feedback.md`
